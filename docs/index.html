Halaman ini adalah versi statis yang di-host di GitHub Pages, hanya untuk informasi.

Kenapa fitur ujiannya tidak jalan di sini?

GitHub Pages hanya menyajikan file statis (HTML/CSS/JS) dan tidak menjalankan server backend. Fitur seperti pembuatan ujian, short URL dengan batas waktu, sesi peserta, dan penyimpanan hasil membutuhkan server Node.js yang berjalan terus (Express).

Cara menjalankan versi lengkap:
  1. VPS/Hosting: npm install lalu npm start
  2. Vercel (gratis): hubungkan repo ini, deploy otomatis lewat vercel.json

Lihat README.md di repository untuk tutorial lengkap dan TOS.
